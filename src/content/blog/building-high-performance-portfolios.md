# Designing for High-Contrast Minimalist Typography

Typography is the foundational structure of brutalist and editorial design systems. When designing an engineer's portfolio, aligning the visual hierarchy with code aesthetics establishes immediate credibility.

## Font Pairing Strategy

1. **Heading & Navigation**: `Iosevka NFM` provides structured, tabular character widths that ground the layout in engineering tooling.
2. **Body Copy**: `Overpass` provides humanistic geometric proportions, ensuring extended reading comfort.

## Token Uniformity

By maintaining strict semantic color tokens (`#f2f0ef` for canvas and `#191919` for ink), light and dark modes achieve exact optical parity.
